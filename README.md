# 今天吃点啥

可在手机和电脑浏览器使用的外卖推荐交互演示，使用固定的示例菜品数据。

## 交互

- 选择 20 元、30 元或 50 元预算。
- 点击「换一个推荐」，展示另一道符合预算的菜品。
- 查看菜品名称、价格、预计配送时间和推荐理由。
- 选择保存在当前浏览器中，刷新后可以继续查看。

## 发布

GitHub Pages 从 `main` 分支的根目录发布 `index.html`。

## 开发

直接编辑 `index.html`。所有样式、交互和演示数据都包含在这个文件中。

本地预览：`python3 -m http.server 8000`，然后打开 `http://localhost:8000`。
